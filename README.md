# Legendary Collection — TTM Sports Autograph Community

An independent, community-maintained resource for Through-The-Mail (TTM) sports autograph collecting. Built for collectors to look up signer addresses, track mailings, learn card-protection best practices, and share collecting results.

**Live Site:** https://ayoncamilo44-bit.github.io/Legendary-Collection/

---

## Features & Pages
- **Signer Directory (`directory.html`):** Browse community-maintained TTM signer records and reported response trends.
- **Personal Dashboard (`dashboard.html`):** Sign in with Google to track your own outgoing requests, returns, and collecting log.
- **Community Feed (`community.html`):** Share recent TTM successes and learn from fellow collectors.
- **Card Showcase (`showcase.html`):** Highlight favorite signed cards and the stories behind them.
- **Guides & Supplies (`guides.html`, `supplies.html`, `hobby-hub.html`):** Beginner TTM instructions, card-packing tips, and recommended collecting supplies.
- **Add Signer (`signer.html`):** Submit new signer info to help grow the community directory.

## Tech Stack
- **Frontend:** HTML, Tailwind CSS, Lucide Icons, custom ambient floating-card UI
- **Auth & Data:** Supabase (`./js/auth.js`)
- **Hosting:** GitHub Pages
